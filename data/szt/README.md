# szt 用户数据

这份数据由账号使用者授权随本次源码上传到 GitHub。`workspace.json` 是 `szt` 工作区在北京时间 2026-11-17 10:32 导出的 JSON v6 快照，包含当时的聊天、任务、日历、课表、偏好、档案、计划、执行反馈和草案记录。

快照包含 7 个会话、21 条消息、6 项任务、128 条按日期课程、1 条保护时间、2 项独立日历事项，以及相关计划和引用。先前导入的发布汇报演示初始数据也包含在内。完整数据恢复和外键一致性已在独立数据库验证。

## 在新安装中恢复

1. 按仓库根目录的 [启动说明](../../README.md#本地运行)安装依赖并启动后端、前端。
2. 打开 `/register`，注册用户名 `szt` 并自行设置密码。已有此账号时直接登录。
3. 进入“我的档案”的“数据与备份”，点击“从 JSON 备份恢复”，选择本目录的 [workspace.json](workspace.json) 并确认。
4. 导入完成后，重新打开聊天或日历查看记录。发布汇报数据位于 2026-11-23 至 2026-11-29 所在周，完整课表覆盖 2026-08-31 至 2026-12-29。

导入会替换当前登录账号的业务数据，系统会先创建本地安全备份。恢复按现有规则更新工作区缓存标识和数据版本，使旧的待确认候选失效。

## 账号与配置

登录密码、密码散列、登录会话和服务端 `.env` 由各安装自行管理。注册后恢复快照即可将这份业务数据归入当前登录账号。本地原有 `szt` 账号继续使用原来的密码。
