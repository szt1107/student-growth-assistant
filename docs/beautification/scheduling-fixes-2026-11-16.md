# 全天日程与活动草案修复（2026-11-16）

本次分支：`codex/beautified-all-day-scheduling`，基于`美化版`的`887263f`；在单独克隆的`student-growth-assistant-beautified`开发。该记录描述本次功能修复，初始视觉版本的历史验证另见[美化版验证报告](verification.md)。

## 用户可见行为

- “我今天早上要进行升旗仪式，七点半开始，预计半个小时，请你帮我规划草案”会生成名称为“升旗仪式”、时长30分钟、开始07:30、结束08:00的草案。
- 具体开始钟点直接作为时间要求，不再要求用户附加“必须、固定”等字眼。只有明确说“左右、可以调整”等，才允许自动避让。指定时间已过或与课程、保护时间及正式安排冲突时，保留原时间并说明原因，不静默修改。
- 未提供时段或钟点时，默认08:00。只给出凌晨、上午、中午、下午或晚上时，仍按用户的时段生成建议。
- 排程、空闲时段查询和手动编辑支持全天24小时，支持指定跨午夜安排；保留5分钟网格、真实截止、锁定和冲突检查。单个连续任务段最多24小时，长任务可分段。
- 活动名称不再依赖学习任务关键词列表；补齐“半个小时”的识别，并避免把补充截止时间的“前完成”等文字误当作新名称。
- 未采用的旧草案可从原始用户消息恢复被默认值覆盖的名称、时长和时间。页面提示保存草案编辑以重新计算；读取本身不改写数据库，不覆盖手动确认的字段。
- 草案依旧需要用户确认才会写入正式任务和日程。用户未给出的硬截止时间保持为空。

## 应用修改

重启正在运行的美化版后端，并刷新网页。继续使用 `app_env` 时，在支持Conda的PowerShell中激活已有`app_env`，进入美化版根目录运行：

```powershell
conda activate app_env
$env:SGA_DEMO = "0"
$env:SGA_DATABASE_PATH = Join-Path $PWD 'backend/data/app.db'
python -m uvicorn app.main:app --app-dir backend --host 127.0.0.1 --port 8002
```

另一个终端启动前端：

```powershell
# 先进入同一份美化版项目根目录
$env:VITE_API_BASE_URL = "http://127.0.0.1:8002"
npm.cmd --prefix frontend run dev -- --host 127.0.0.1 --port 5175 --strictPort
```

打开 http://127.0.0.1:5175/。旧草案出现重新计算提示时，点击“保存草案编辑”，或发送新的活动请求生成草案。
