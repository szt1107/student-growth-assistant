## 交付与使用边界

`美化版` 文件夹包含可直接运行的本机依赖；`美化版.zip` 保留完整源码、生产构建、配图和上述资料，排除虚拟环境、node_modules、数据库、密钥、日志和测试临时文件。异机安装步骤见[美化版说明](../../美化版说明.md)。

GitHub 的 `美化版` 分支仅保留源码、图片、说明和验证资料，不提交本机依赖、压缩包或构建产物。远端 main 核对仍为报告所列基础提交，321 个原有文件的改动范围保持不变。

数据库为本目录独立 SQLite，不复制原项目个人数据或配置。AI、语音服务的真实 Provider 功能没有进行付费联调，仍需按原说明自行配置。项目仍遵循原仓库的作者和许可说明。
